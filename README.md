# Sinistralité France

Application web statique de consultation des statistiques d'accidents du travail,
de maladies professionnelles et d'accidents de trajet par secteur d'activité (codes NAF),
construites à partir des publications ouvertes de l'Assurance Maladie (Ameli).

Application : https://ayming-sinistralite.github.io/
