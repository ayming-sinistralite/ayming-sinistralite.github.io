Cookies et stockage local

Aucun cookie

Ce site ne dépose aucun cookie. Il n'utilise aucun outil de mesure d'audience, aucun outil publicitaire et aucun bouton de réseau social qui suivrait votre navigation.

Ce que votre navigateur garde sur votre appareil

Pour vous éviter de tout ressaisir, l'outil garde quelques informations dans le stockage local de votre navigateur. Elles restent sur votre appareil et ne sont pas transmises à Ayming, sauf la provenance de votre visite, jointe à votre demande de diagnostic si vous en faites une.

  • Le prénom, le secteur et la raison de votre visite, si vous les indiquez à l'accueil.
  • Les réponses de vos rapports, pour les rouvrir sans refaire le questionnaire.
  • Le thème clair ou sombre, l'état du menu latéral, les visites guidées et les premiers pas déjà faits.
  • La provenance de votre visite (la campagne ou le lien qui vous a amené), lue dans l'adresse de la page.

Pour les effacer, supprimez les données de ce site dans les réglages de votre navigateur. L'outil fonctionne aussi sans elles.

Les services appelés par le site

  • jsDelivr, pour les bibliothèques qui dessinent les graphiques de l'outil.
  • L'API Recherche d'entreprises de l'État, quand vous cherchez le nom de votre entreprise dans le questionnaire.
  • Le formulaire d'Ayming (Pardot), seulement quand vous demandez votre diagnostic.

Comme pour toute page web, votre navigateur leur transmet votre adresse IP pour recevoir leur réponse.

Les liens vers d'autres sites

Les liens vers ayming.fr, acciline.com ou LinkedIn ouvrent des sites qui appliquent leur propre politique de cookies.

Le traitement de vos données et vos droits sont décrits dans la politique de protection des données personnelles d'Ayming. Pour exercer vos droits, écrivez à dpo@ayming.com. Voir aussi les mentions légales.
